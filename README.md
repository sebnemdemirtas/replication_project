# STAT 5200 Replication Project

This STAT 5200 project reproduces the paper:

Fong, J., Natan, O. R., & Pantle, R. (2026). Consumer inferences from product rankings: The role of
beliefsinsearchbehavior. Management Science, ArticlesinAdvance,1–21. doi:10.1287/mnsc.2025.00761.


## Repository layout

- `code/` contains the replication scripts.
- `data/` is a local folder for the authors' processed data.It will not be shared on github. It can be accessed through the original source: https://services.informs.org/dataset/mnsc/download.php?doi=mnsc.2025.00761
- `results/figures/` and `results/tables/` contain the replication outputs.
- To reproduce the results, simply import the repository and run the code file.

## Reference

Fong, J., Natan, O. R., & Pantle, R. (2026). Consumer inferences from product rankings: The role of beliefs in search behavior. *Management Science*. https://doi.org/10.1287/mnsc.2025.00761
